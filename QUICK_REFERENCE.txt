QUICK START (3 STEPS)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. CREATE SLACK APP
   → Go to https://api.slack.com/apps
   → Create New App → From scratch
   → Name: Jarvis
   → Save Signing Secret + Bot Token

2. DEPLOY TO RAILWAY
   → https://railway.app → New Project
   → Connect your GitHub repo (or upload files)
   → Set environment variables:
     - SLACK_SIGNING_SECRET
     - SLACK_BOT_TOKEN
     - CLAUDE_API_KEY
     - NODE_ENV=production
   → Copy Railway URL

3. CONFIGURE SLACK EVENTS
   → Event Subscriptions → Enable Events
   → Request URL: https://[RAILWAY-URL]/slack/events
   → Subscribe to: app_mention, message.channels
   → Reinstall App

Test: Type "@jarvis hello" in Slack → Should respond!
